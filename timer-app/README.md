# Timer

Stopwatch, Pomodoro, calendar and reports in one installable web app. No build step.

Live at `https://YOUR-USERNAME.github.io/YOUR-REPO/` once GitHub Pages is on (Settings > Pages > Deploy from a branch > main / root).

Data is stored in your own browser (IndexedDB + localStorage). Use Settings (gear) > Backup to export it.

## Install
- iPhone: open the link in Safari > Share > Add to Home Screen.
- Android/desktop Chrome: menu > Install app.

## Update
Edit `index.html`, bump `CACHE` in `sw.js` (e.g. `timer-v2`), commit and push.
